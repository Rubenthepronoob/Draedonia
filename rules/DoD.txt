Definition of Done (DoD)
1. Functionaliteit
•	De functionaliteit werkt zoals bedoeld.
•	Alle benodigde onderdelen zijn geïmplementeerd.
•	De functionaliteit werkt op de afgesproken apparaten/browsers.
•	Er zijn geen bekende kritieke bugs.
2. Code
•	De code is overzichtelijk en begrijpelijk.
•	De code volgt de afgesproken naamgeving en structuur.
•	Onnodige code is verwijderd.
•	De code is getest.
3. Testen
•	De functionaliteit is handmatig getest.
•	Belangrijke uitzonderingen/foutmeldingen zijn getest.
•	Bestaande functionaliteiten werken nog steeds.
•	Eventuele gevonden bugs zijn opgelost of geregistreerd.
4. Vormgeving / UI
•	De vormgeving voldoet aan het ontwerp.
•	Teksten en afbeeldingen zijn correct.
•	Knoppen en andere interactieve elementen werken.
•	De interface is duidelijk en gebruiksvriendelijk.
5. Documentatie
•	De benodigde documentatie is bijgewerkt.
•	Belangrijke wijzigingen zijn beschreven.
•	Eventuele installatie- of gebruiksinstructies zijn toegevoegd.
6. Review
•	Het resultaat is gecontroleerd door een teamlid/docent/opdrachtgever.
•	Feedback is verwerkt.
•	De functionaliteit voldoet aan de vooraf afgesproken eisen.
7. Klaar voor oplevering
•	Alle bovenstaande punten zijn afgerond.
•	Er zijn geen blokkerende problemen meer.
•	De definitieve versie is opgeslagen/geüpload.
•	De taak kan worden afgesloten als "Done".
